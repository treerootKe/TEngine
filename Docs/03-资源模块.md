## 2. 加载管线（读代码顺序：ResourceModule.cs:692-922）

任何一次加载都走同一条路：

```
location ──CheckLocationValid──→ 缓存key(默认包=location, 其他包="包名/location")
   │
   ├─ TryWaitingLoading(key)      同一资源并发加载去重（编辑器下 60s 超时告警）
   ├─ _assetPool.Spawn(key)       命中 → 直接返回（引用计数+1）
   └─ 未命中 → YooAsset.LoadAssetSync/Async 拿 AssetHandle
        └─ AssetObject.Create(key,asset,handle,this) → 池.Register
```

释放：`UnloadAsset(asset)` = `_assetPool.Unspawn(asset)`（引用计数-1）。计数归零的对象在 `AssetExpireTime`（默认过期秒数）后被池释放，释放时 `AssetObject.Release` 里 `handle.Dispose()` 归还给 YooAsset（ResourceModule.AssetObject.cs:50-61）。

**预制体专用通道**：`LoadGameObject/LoadGameObjectAsync` 在加载后调 `AssetsReference.Instantiate` —— 给实例挂一个 `AssetsReference` 组件记录来源 prefab，`OnDestroy` 时自动 `UnloadAsset`（Extension/AssetsReference.cs:95-108）。**所以实例化物只需 Destroy，不用手动还引用**。

## 3. 操作手册：加载本仓库自带素材

地址规则：AB 收集器对 `Assets/AssetRaw/**` 全部采用 **AddressByFileName**（地址=文件名去扩展名，见 §5）。

**① 加载预制体并实例化（同步/异步）**
```csharp
// AssetRaw/Actor/Cube.prefab → 地址 "Cube"
GameObject cube = GameModule.Resource.LoadGameObject("Cube", parent);

// AssetRaw/UI/BattleMainUI.prefab → 地址 "BattleMainUI"（异步、可取消）
GameObject panel = await GameModule.Resource.LoadGameObjectAsync(
    "BattleMainUI", parent, this.GetCancellationTokenOnDestroy());
// Destroy(panel) 时自动归还引用，无需 UnloadAsset
```

**② 加载图片/Sprite 给 UI**
```csharp
// 首选：SetSprite 扩展（内部走 ResourceExtComponent，自动管理加载与释放）
using TEngine;
_image.SetSprite("Play_Joystick_bg");          // AssetRaw/UIRaw/Atlas/Battle/Play_Joystick_bg.png

// 图集子图：location=含多个子Sprite的图集纹理资源, spriteName=子图名
// （内部走 YooAssets.LoadSubAssetsAsync<Sprite>(location)，需要该资源导入为 Multi-Sprite）
_image.SetSubSprite("MyAtlasTexture", "Slider11_Fill_Blue", setNativeSize: true);

// 手动方式：Sprite s = await GameModule.Resource.LoadAssetAsync<Sprite>("Play_Joystick_bg");
// 用完必须 GameModule.Resource.UnloadAsset(s);
```

**③ 加载音频/文本等普通资产**
```csharp
var clip = await GameModule.Resource.LoadAssetAsync<AudioClip>("music_bg");
var text = GameModule.Resource.LoadAsset<TextAsset>("GameLogic"); // 热更DLL也这么读
```

**④ 回调风格（进度回调场景）**
```csharp
var callbacks = new LoadAssetCallbacks(
    (name, asset, duration, ud) => { },
    (name, status, msg, ud) => { },
    (name, progress, ud) => { /* 进度 */ });
GameModule.Resource.LoadAssetAsync("Cube", 100, callbacks, null);
```

**⑤ 多资源包（packageName 参数）**
```csharp
// 先确保目标包已 InitPackage，之后所有 API 末尾都有 packageName 重载
await GameModule.Resource.InitPackage("HallPackage");
var go = GameModule.Resource.LoadGameObject("SomeUI", packageName: "HallPackage");
```

**释放纪律（重要）**
- `LoadAsset/LoadAssetAsync`（非 GameObject 版）：**必须**手动 `UnloadAsset` 配对
- `LoadGameObject*`：Destroy 实例即可（AssetsReference 代办）
- `SetSprite/SetSubSprite`：内部自管，勿重复释放
- 切场景/低内存：`UnloadUnusedAssets()`（归零资源）；`ForceUnloadAllAssets()`（全部，慎用）

## 4. 运行模式（EPlayMode）与版本链

`ResourceModule.InitPackage`（ResourceModule.cs:140-261）按模式创建 YooAsset 包：

| 模式 | 行为 | 谁用 |
|---|---|---|
| `EditorSimulateMode` | 模拟构建，直接引用 AssetDatabase，不用真 AB | 编辑器开发 |
| `OfflinePlayMode` | 只读 StreamingAssets 内置 AB，不联网 | 单机/首包 |
| `HostPlayMode` | 内置 + 远端 CDN 增量下载 | 真机热更 |
| `WebPlayMode` | WebGL 远端/本地（含微信小游戏分支） | Web |

编辑器下模式取 `EditorPrefs.GetInt("EditorPlayMode")`（TEngine 调试窗口切换）。

版本与下载 API（流程链 5-8 步的底层）：`RequestPackageVersionAsync` → `UpdatePackageManifestAsync(version)` → `CreateResourceDownloader()` → `Downloader.BeginDownload()` → `ClearCacheFilesAsync()`。

## 5. AB 打包：把资源做成 AssetBundle

**收集规则**（配置资产：`Assets/Editor/AssetBundleCollector/AssetBundleCollectorSetting.asset`）：
- 包名：`DefaultPackage`
- 分组：`AssetRaw/` 下每个子目录一组（Actor/Audios/Configs/DLL/Effects/Fonts/Materials/Scenes/Shaders/UI/UIRaw...）
- 每组统一 `AddressRuleName=AddressByFileName`（**加载地址 = 文件名**）、`PackRuleName=PackDirectory`（目录打成一个 bundle）
- Tag 用法：给收集器或资源打 Tag（如 `PRELOAD`），运行时 `GetAssetInfos("PRELOAD")` 按标签批量取（ProcedurePreload 就这么干）

**操作步骤：**
1. 菜单 `YooAsset/AssetBundle Collector` 检查/修改收集规则（本项目默认已配好）
2. 菜单 `TEngine/Build/一键打包AssetBundle _F8`（或 `YooAsset/AssetBundle Builder`）产出 bundles → 输出目录（OutputRoot）下按平台分目录
3. OfflinePlayMode 需要 AB 在 StreamingAssets：UpdateSetting 勾 `isAutoAssetCopeToBuildAddress` 或手动拷贝；找不到清单时会报 `PackageManifest_DefaultPackage.version 404`（ProcedureInitPackage.cs:102 有对应提示）
4. 加密：`ResourceModule.EncryptionType = FileOffSet/FileStream`（XOR/偏移，Services.cs 实现，打包与加载两侧对应）

**"资源已打包成 AB 后如何加载"——答案：代码完全不变。** location 体系下同一行 `LoadGameObject("Cube")`：
- EditorSimulateMode：直连 AssetDatabase
- Offline/Host：YooAsset 内部定位到所在 bundle → 先加载 bundle 再取资产
- Host 模式若该资产在远端且未下载，`HasAsset` 会返回 `AssetOnline`；流程链的下载器负责提前拉齐（也可 `IsNeedDownloadFromRemote(location)` 单点查询）

## 7. 常见坑

- 地址是**文件名不是路径**（AddressByFileName）；同包内文件重名会撞地址，UI prefab 尤其注意
- `LoadAssetAsync` 的非 await 版（返回 UniTaskVoid + callback）加载失败回调 null；await 版失败返回 null 且 Log.Error
- 未 InitPackage 就加载 → `The package does not exist`；默认包由启动流程初始化，自定义包要自己 init
- `AutoUnloadBundleWhenUnused` 默认 false；true 时引用归零的 bundle 会被自动卸载（省内存但有回载成本）
