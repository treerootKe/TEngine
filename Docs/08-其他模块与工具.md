# 08 其他模块与工具

## 1. DebugerModule（Module/DebugerModule/，33 文件）

编辑器/真机调试面板（仿 GameFramework 风格）：运行时 FPS/内存/日志窗口 + 各系统 Profiler 面板。
- 激活方式：`Debugger.Instance.ActiveWindowType`（AlwaysOpen / OnlyOpenWhenDevelopment / OnlyOpenInEditor，RootModule 上配置）
- 相关：`UIModule` 会按此开关决定是否挂 ErrorLogger（运行时异常弹窗，UIModule.cs:69-93）
- 编辑器资源模式切换（EditorPrefs "EditorPlayMode"）也在调试器窗口里

## 2. LocalizationModule（Module/LocalizationModule/，78 文件）

内嵌了 Unity Localization 风格的目标系统（LocalizeTarget_TextMeshPro_UGUI/Label 等 Targets）+ 自有语言管理：
```csharp
var loc = GameModule.Localization;
loc.Language = Language.ChineseSimplified;      // ProcedureLaunch 启动时已按存档初始化
```
启动链里语言持久化键：`Constant.Setting.Language`（ProcedureLaunch.cs:45-81）。TMPro 相关 Target 需要 textmeshpro 包（manifest 已含 3.0.9）。

## 4. Launcher 启动 UI（Assets/Launcher/Scripts/，AOT 侧）

热更代码就绪**之前**的界面体系（不走 GameLogic 的 UIModule，自己的 UIBase）：
```csharp
LauncherMgr.Initialize();                       // ProcedureLaunch 调用
LauncherMgr.ShowUI<LoadUpdateUI>("初始化资源中...");  // 进度提示
LauncherMgr.RefreshProgress(0.6f);             // 进度条
LauncherMgr.ShowMessageBox(desc, onConfirm, onCancel); // 原生风格弹窗
LauncherMgr.HideAllUI();                       // ProcedureStartGame 收尾
LoadText.Instance.InitConfigData(null);        // 启动期文案表（热更前文本）
```
流程链大量使用（见 01 篇表格）。改启动界面在这套，改游戏内界面在 GameLogic/UIModule —— 两套别混。

## 8. 学习路径建议（配合本手册）

1. 跑通：main.unity Play → 看 Console 出现 `======= 看到此条日志代表你成功运行了热更新代码 =======`（GameApp.cs:29），对照 01 篇流程表逐条在代码里打断点走一遍
2. 资源练习：在任意热更脚本里 `LoadGameObject("Cube")` 出一个方块；用 `Assets/Get Asset Path` 核对地址
3. UI 练习：复制 TestUI.prefab 走 04 篇步骤新增一个窗口并打开
4. 打包练习：F8 出 AB → 切 OfflinePlayMode 验证"不进编辑器模拟也能加载"
5. 热更练习：改 BattleMainUI 一行代码 → 走 07 篇打包链 → HostPlayMode 配本地 http 服务（8081）验证增量更新
