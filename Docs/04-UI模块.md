# 04 UI 模块（热更侧 · GameLogic/UIModule）

源码：`Assets/GameScripts/HotFix/GameLogic/Module/UIModule/`（注意整套 UI 系统在**热更程序集**里）

## 1. 文件结构

| 文件 | 职责 |
|---|---|
| `UIModule.cs` (731行) | 窗口栈管理、层级排序、显隐调度、开关窗 API |
| `UIWindow.cs` | 窗口基类：加载/创建/销毁内部流水线、Canvas 深度与可见性 |
| `UIBase.cs` | Window/Widget 公共基类：生命周期虚函数、FindChild、事件、Widget 工厂、Icon 列表工具 |
| `UIWidget.cs` | 子控件基类（挂在窗口 prefab 子节点上复用逻辑） |
| `WindowAttribute.cs` | 窗口声明特性 + `UILayer` 枚举 |
| `UIBindComponent/` | BindComponent 组件（ScriptGenerator 生成绑定用） |
| `IUIResourceLoader.cs` | UI→资源模块的桥接口（UIResourceLoader 实现） |

## 2. 窗口栈与层级（UIModule.cs）

- 数据结构是**单一 List 模拟的分层栈** `_uiStack`：Push 时按 `WindowLayer` 插到同层的最后一个位置（Push, UIModule.cs:666-704）
- 层级枚举：`Bottom(0) < UI(1) < Top(2) < Tips(3) < System(4)`
- 深度公式（OnSortWindowDepth）：`depth = layer * 2000`，同层每个窗口 +100；子 Canvas 随主 Canvas 平移（UIWindow.cs:110-124）
- 全屏遮挡（OnSetWindowVisible）：从栈顶往下找第一个"已 Prepare 且 FullScreen"的窗口，其下全部 `Visible=false`
- 显隐实现：切 `gameObject.layer` 在 `UI(5)`/`Ignore Raycast(2)` 之间 —— 不可见即不可交互，UGUI 也不参与渲染射线

## 3. 窗口生命周期（谁在什么时候调你）

`UIWindow` 内部流水线（UIWindow.cs:314-458）：

```
ShowUIAsync<T>()
 └─ InternalLoad      资源加载（UIModule.Resource，非 AB 资源走 FromResources 分支）
     └─ Handle_Completed   挂 Canvas/GraphicRaycaster 引用、overrideSorting=true
         └─ InternalCreate 依次执行：
             ① Inject()             UIBase.Injector 静态委托（依赖注入口）
             ② ScriptGenerator()    ★生成代码绑定控件字段
             ③ BindMemberProperty()
             ④ RegisterEvent()
             ⑤ OnCreate()           业务初始化写这里
         └─ InternalRefresh → OnRefresh()   每次再次 Show 也会走（携带 userDatas）
 ── 每帧 InternalUpdate → OnUpdate()（可见才调；有活跃 Widget 时窗口 OnUpdate 仍会调）
 └─ CloseUI/InternalDestroy：
     RemoveAllUIEvent（自动注销 AddUIEvent 注册的事件）→ 子 Widget 销毁
     → OnDestroy() → Destroy(panel)（AssetsReference 自动还资源引用）
```

再次 Show 已存在窗口：不重新加载，Pop+Push 置顶并触发 `OnWindowPrepare → InternalRefresh`（TryGetWindow, UIModule.cs:323-336）。

## 4. 声明一个窗口：WindowAttribute

```csharp
[Window(UILayer.UI, location: "BattleMainUI")]     // location 缺省=类名
class BattleMainUI : UIWindow { }
```
参数（WindowAttribute.cs）：`windowLayer` 层级 / `location` 资源地址（默认类名）/ `fullScreen` 全屏标记 / `hideTimeToClose` HideUI 后多少秒自动关（默认 10）/ `fromResources` 走 Resources.Load 而非 AB。

## 5. 操作手册：新增一个窗口（完整步骤）

以仓库自带素材演示（UI prefab 放 `Assets/AssetRaw/UI/`，地址=文件名）：

1. **做 prefab**：UGUI 面板，根节点必须挂 `Canvas`（否则 Handle_Completed 抛异常）+ `GraphicRaycaster`；需要被脚本引用的节点命名加 `m_` 前缀（如 `m_btnClose`、`m_txtTitle`），List 节点用 `item` 前缀
2. **生成绑定代码**：Hierarchy 选中 prefab 根 → 右键 `GameObject/ScriptGenerator/UIPropertyAndListener`（或 BindComponent 变体）→ 生成 `XXX.cs`（含 `ScriptGenerator()` 内的 FindChildComponent 绑定与按钮监听桩）。生成器配置：`TEngine/Create ScriptGeneratorSetting`
3. **写业务类**（生成文件已含框架，手动写则如下）：
```csharp
using TEngine;
using UnityEngine;
using UnityEngine.UI;

namespace GameLogic
{
    [Window(UILayer.UI, location: "TestUI")]   // AssetRaw/UI/TestUI.prefab
    class TestUI : UIWindow
    {
        private Text m_txtTitle;
        private Button m_btnClose;

        protected override void ScriptGenerator()
        {
            m_txtTitle = FindChildComponent<Text>("m_txtTitle");
            m_btnClose = FindChildComponent<Button>("m_btnClose");
        }

        protected override void RegisterEvent()
        {
            AddUIEvent<int>((int)GameEventDef.SomeEvent, OnSomeEvent); // 见05篇
        }

        protected override void OnCreate()
        {
            m_txtTitle.text = "Hello TEngine";
            m_btnClose.onClick.AddListener(Close);   // Close() 基类内置
        }

        protected override void OnRefresh()
        {
            if (UserData is string title) m_txtTitle.text = title; // 再次Show携带参数
        }
    }
}
```
4. **打开/关闭**：
```csharp
GameModule.UI.ShowUIAsync<TestUI>();                      // 异步（常用）
GameModule.UI.ShowUI<TestUI>("标题参数");                  // 同步；参数进 UserDatas
var ui = await GameModule.UI.ShowUIAsyncAwait<TestUI>();  // 等窗口就绪拿实例
GameModule.UI.CloseUI<TestUI>();
GameModule.UI.HideUI<TestUI>();      // HideTimeToClose 秒后自动 Close，期间再Show会取消计时
GameModule.UI.CloseAllWithOut<TestUI>();                  // 关闭其他
```
5. prefab 移入 `AssetRaw/UI/` 后即被 AB 收集器覆盖（地址=文件名）。

## 6. UIWidget：窗口内复用子件

Widget = 挂到窗口子节点上的小逻辑单元（UIWidget.cs），适合作列表项/通用控件：
```csharp
// 已在窗口里：以子节点路径创建
var item = CreateWidget<RoleItem>("m_list/m_itemRoleInfo");
// 按 prefab 克隆
var icon = CreateWidgetByPrefab<ItemWidget>(prefab, parent);
// 按资源地址（会实例化一个新 prefab）
var w = await CreateWidgetByPathAsync<ItemWidget>(parent, "ItemWidget");
// 列表数量增删（含每帧限量防卡顿的异步版 AsyncAdjustIconNum）
AdjustIconNum(_icons, 10, parent, prefab);
```
Widget 生命周期与窗口绑定：窗口 InternalDestroy 时逐个 CallDestroy。`OnUpdate` 返回 true 才继续参与窗口轮询（UIBase.cs:232-239 脏标记机制）。

## 7. 其他要点

- **UIRoot**：场景里必须有名为 "UIRoot" 的物体（含 Canvas + Camera），UIModule.OnInit 查找失败直接 Fatal（UIModule.cs:51-60）
- **安全区**：`UIModule.ApplyScreenSafeRect(Screen.safeArea)`、窗口内 `SetUIFit(rect)` 做刘海屏适配；`SimulateIPhoneXNotchScreen()` 模拟测试
- **UI 事件自动注销**：`AddUIEvent` 注册的处理器记在池化 GameEventMgr 里，窗口销毁 `RemoveAllUIEvent` 批量注销 —— **窗口内订阅必须用 AddUIEvent，不要裸用 GameEvent.AddEventListener**
- 打开窗口时窗口对象是 new 出来的纯 C# 对象（无 MonoBehaviour），UIModule 靠 `_uiStack` 持有；`IsAnyLoading()` 可查是否有窗口在加载中
