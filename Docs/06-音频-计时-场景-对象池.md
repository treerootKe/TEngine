# 06 音频 / 计时 / 场景 / 对象池

四个功能模块的速查手册。均经 `GameModule.XXX` 或 `ModuleSystem.GetModule<>()` 访问。

## 1. AudioModule（Module/AudioModule/，9 文件）

**结构**：`AudioModule` 管理四类通道（`AudioType`: Music 音乐 / Sound 音效 / UISound 界面音 / Voice 人声），每通道一个 `AudioGroup`（代理池复用 AudioSource），配置来自 `Assets/TEngine/Settings/AudioSetting.asset`（`Settings.AudioSetting`）。

**API（IAudioModule）**：
```csharp
var audio = GameModule.Audio;
audio.MusicVolume = 0.8f;               // 音量（每通道独立 Volume/Enable）
audio.MusicEnable = true;

// 播放：地址同样是 AssetRaw 内文件名；返回 AudioAgent 可控停
AudioAgent agent = audio.Play(AudioType.Music, "music_bg", bLoop: true, volume: 1f, bAsync: true);
audio.Play(AudioType.Sound, "click");

audio.Stop(AudioType.Music, fadeout: true);
audio.StopAll(fadeout: false);

// 声音池：常播音效驻留内存
audio.PutInAudioPool(new List<string>{ "click", "coin" });
audio.RemoveClipFromPool(...); audio.CleanSoundPool();
```
启动恢复：`ProcedureLaunch.InitSoundSettings()` 从 PlayerPrefs 读回四通道开关音量（键名见 `Constant.Setting`）。

## 2. TimerModule（Module/TimerModule/，2 文件）

帧驱动的定时器池，ID 制：
```csharp
int id = GameModule.Timer.AddTimer(OnTick, 3f);                    // 3秒后（一次性）
int id2 = GameModule.Timer.AddTimer(OnTick, 1f, isLoop: true, isUnscaled: false, args);
GameModule.Timer.GetLeftTime(id);      // 剩余秒
GameModule.Timer.Resume(id);           // 恢复已 Stop 的计时器
GameModule.Timer.ResetTimer(id, 5f, isLoop: true);                 // 重设时长
GameModule.Timer.RemoveTimer(id);      // 注销（窗口销毁记得清理自己加的）
GameModule.Timer.RemoveAllTimer();
```
签名 `TimerHandler(Action<object[]>)`。框架内部也在用：UIModule.HideUI 的延时自动关窗就是 AddTimer（UIModule.cs:411-414）。

## 3. SceneModule（Module/SceneModule/，2 文件）

薄封装 YooAsset 场景加载（场景也要进 AB 收集器，`AssetRaw/Scenes` 组）：
```csharp
await GameModule.Scene.LoadSceneAsync("battle");   // 地址=场景文件名
await GameModule.Scene.UnLoadSceneAsync("battle");
```
加载走 YooAsset 的 SceneHandle，回调风格 `LoadSceneCallbacks` 在 ResourceModule/Callback/ 下。

## 4. ObjectPoolModule（Module/ObjectPoolModule/，9 文件）

GameFramework 经典实现（ObjectBase/IObjectPool/ObjectPoolManager 三层）：
- **使用方视角**：`CreateSingleSpawnObjectPool<T>` / `CreateMultiSpawnObjectPool<T>(name)` 建池 → `pool.Spawn(key)` 取 / `pool.Register(obj, true)` 存 / `pool.Unspawn(obj)` 还
- 池参数：`Capacity / ExpireTime / AutoReleaseInterval / Priority`
- **资源模块整个缓存层就建在它上面**（ResourceModule.Pool.cs:65 `"Asset Pool"`）；自定义池化（如子弹、弹幕）照抄该模式：继承 `ObjectBase`（配合 `MemoryPool.Acquire`）实现 `Release(bool isShutdown)`
- 低内存：`pool.ReleaseAllUnused()`（RootModule.OnLowMemory 自动调用）

## 5. FsmModule（Module/FsmModule/，6 文件）

通用有限状态机：`Fsm<T>` 持有数据字典 + 当前 `FsmState<T>`；ProcedureModule 就是用它驱动的（`ProcedureSetting.StartProcedure` → `IFsmModule.CreateFsm` + `IProcedureModule.Initialize`）。业务要做状态机（如怪物 AI）：
```csharp
var fsm = GameModule.Fsm.CreateFsm<Monster>(owner, new IdleState(), new ChaseState());
fsm.Start<IdleState>();
// FsmState<T> 里 OnEnter/OnUpdate/OnLeave/OnChangeState
```

## 6. 配套关系图

```
RootModule(低内存) ─→ ObjectPool.ReleaseAllUnused + Resource.OnLowMemory
UIModule.HideUI ─→ TimerModule.AddTimer(延时关窗)
AudioSetting.asset ─→ AudioModule.Initialize(groups)
ResourceModule ─→ ObjectPoolModule(AssetObject 池) + YooAsset
ProcedureModule ─→ FsmModule(流程即状态)
```
